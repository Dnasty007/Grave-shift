# HYTOPIA BIBLE — Master Player Book

**Project Gehenna • Hytopia NEO**

This is the single source of truth and living knowledge base for building **Project Gehenna** in the Hytopia NEO engine.

It is designed to be used by humans and AIs alike (Grok, Cursor, Claude, and future agents) so that anyone joining the project can quickly become effective and aligned with the vision.

## Philosophy

This Bible exists because:
- Hytopia NEO is still relatively new and documentation can be scattered.
- Building a large-scale Zombies-style game has many hard, recurring problems.
- Multiple AIs will work on this project over time. We need shared memory.

When you discover something painful, important, or non-obvious — **add it here**.
