# Coliseum \& Environment Logic

* **Wave 30 Event**: Design for a cinematic "Final Stand." Logic must support 1,000+ concurrent zombie entities flooding the coliseum.
* **Spawn Zones**: Define 4-8 distinct "Gate" zones around the coliseum perimeter to prevent entity stacking/clumping.
* **Primitive Standards**: All environmental geometry must adhere to "Perfect Primitive Geometry." Use absolute dimensions for floor tiles and pillars to ensure collision stability.
* **Occlusion**: Use Hytopia's occlusion culling to ensure the 1,000-zombie wave doesn't render entities the player can't see.
