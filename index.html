CONTROLS

Desktop

  • W A S D — Move
  • Shift — Sprint
  • Space — Jump
  • V — Hold: weapon wheel (with 3+ guns, desktop). Release V to equip.
  • V / Ctrl — Fly up / down when Fly mode is on in Settings
  • R — Reload
  • E / F — Use / Buy
  • I — Inventory (backpack ammo, drop / load; closes with I or Esc)
  • Q / Tab / mouse wheel — Cycle weapons (owned)
  • C — Toggle first / third person (when enabled in Settings; desktop)
  • Mouse — Aim
  • Left Click — Fire
  • Esc — Close inventory if open, else pause
  • Enter — Restart on death

Mobile

  • Left thumb — Move
  • Right thumb — Aim
  • Fire button — Shoot
  • Reload button — Reload
  • Use button — Buy / open gates
  • Swap button — Next weapon
  • Pause button — Pause
