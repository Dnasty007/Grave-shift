MAP SELECT IMAGES
-----------------
Drop one image per map here. The menu shows it on that map's card.
Filenames (PNG or JPG both work — the card tries .png first):

  industrial_yard.png
  high_bastion.png
  the_sprawl.png
  draculas_castle.png
  ice_map.png
  test_zone.png
  gehinnom.png        (the teaser/coming-soon card)

Recommended: 16:9 landscape, ~640x360 or larger. If a file is missing,
the card automatically falls back to its built-in gradient — nothing breaks.
